# How to send a change

Most changes start as a message in the StackPack Discord, and the assistant makes them for you. If you have a GitHub account, you can also send a change yourself.

## The short version

1. Fork the repo you want to change.
2. Make a branch and change the files.
3. Open a pull request against the repo you forked.
4. In the description, say what you changed and why.
5. A maintainer reviews it. Small changes usually land the same day.

## Who reviews

Mike and Johan review every change. The assistant runs the security check on everything before it lands. Nobody pushes to the main branch without a review.

## What gets in

- One change doing one thing, described in plain words.
- Prompts, guides and examples other members can use.
- Fixes: a broken link, a typo, a step that does not work.

## What does not

- Anything about a client's or an employer's private work.
- Someone else's work without credit.
- Files carrying passwords, keys or personal details.

## If a pull request sits

A maintainer reads every pull request. If yours needs a change, they say so on the pull request itself.
